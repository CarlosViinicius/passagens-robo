# Robô de passagens MGF → SCL

Abre o Google Voos num Chrome invisível nos servidores do GitHub, lê o menor preço de cada combinação de datas
e manda para o app https://passagens-chile.baudelaire-aviso.workers.dev. Roda às 08h, 10h, 12h, 14h, 16h, 18h, 20h, 22h e 00h (Brasília).

Precisa do segredo `EXT_KEY` (Settings → Secrets and variables → Actions). Para buscar na hora: Actions → Buscar passagens → Run workflow.
